# ✏️ Pencil-3D

Lapsi 3D — tabelë vizatimi interaktive: një laps 3D ndjek kursorin dhe vizaton në letër dixhitale. Modeli 3D rindërtohet proceduralisht pa varësi të vdekura.

## 🚀 Si ta hapësh

Hap `index.html` në browser, pastaj kliko **Live Demo** — vizato me miun në letër.
